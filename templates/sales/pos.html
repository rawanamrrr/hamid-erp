دليل استخدام شاشة البيع (POS)

سيناريوهات العمل والاختصارات الهامة

سيناريوهات البيع (Scripts of Use)

1. بيع مباشر (قطاعي/نقدي)
  1. لا تقم باختيار عميل (سيبقى العميل النقدي الافتراضي).
  2. ابحث عن المنتجات بالاسم أو الباركود (مفتاح F2).
  3. اضغط على المنتجات لإضافتها للسلة.
  4. اضغط دفع (F9)، أدخل المبلغ المستلم ثم Enter للحفظ والطباعة.
2. طلبات الأونلاين والشحن
  1. قم بتفعيل زر أونلاين / شحن من الشريط العلوي.
  2. ابحث عن العميل أو أضفه (تأكد من إدخال العنوان للعميل).
  3. أضف المنتجات المطلوبة.
  4. انقر على المجموع لفتح تفاصيل الطلب، وأضف قيمة الشحن (التوصيل).
  5. اضغط دفع، ثم احفظ الفاتورة كـ "آجل/عند الاستلام" إذا لم يدفع بعد.
{% if sys_settings.market_type == 'pharmacy' %}
3. بيع بالعلبة أو الشريط
  1. اضغط على المنتج — ستظهر نافذة تسألك عن وحدة البيع (علبة / شريط).
  2. اختر الوحدة المناسبة وسيُحسب السعر تلقائياً.
  3. يمكن بيع علب وشرائط متعددة من نفس الدواء في نفس الفاتورة.
{% elif sys_settings.market_type == 'clothes' %}
3. بيع الجملة ونص الجملة
  1. اختر العميل (سيتم تطبيق سعر الجملة أو نص الجملة تلقائياً حسب نوع العميل).
  2. استخدم أزرار الكميات السريعة (6, 12, 48) الموجودة على بطاقة المنتج لإضافتها دفعة واحدة.
  3. قم بإنهاء الدفع أو حفظ الفاتورة مسودة.
{% elif sys_settings.market_type == 'electronics' %}
3. بيع الأجهزة مع الضمان
  1. أضف الجهاز للسلة واضغط على اسمه في السلة لتعديل ملاحظات الضمان.
  2. استخدم حقل الملاحظات لتسجيل رقم السيريال أو شروط الضمان.
  3. احفظ الفاتورة واطبعها كإثبات للضمان.
{% elif sys_settings.market_type == 'grocery' %}
3. بيع بالكميات الكبيرة
  1. اضغط على المنتج وعدّل الكمية مباشرةً في السلة.
  2. يمكن تطبيق خصم مباشر من حقل الخصم في لوحة الدفع.
  3. احفظ وطباعة الفاتورة عند الانتهاء.
{% else %}
3. بيع بسعر مخصص
  1. أضف المنتج للسلة ثم عدّل السعر مباشرةً في حقل السعر داخل السلة.
  2. يمكن تعديل السعر بحرية لكل صنف بشكل مستقل.
  3. احفظ الفاتورة أو اطبعها عند الانتهاء.
{% endif %}
4. الدفع الآجل والدفع المقسم
  1. في شاشة الدفع (F9)، يمكنك إدخال المبالغ المدفوعة في (كاش، محفظة، إنستاباي) في نفس الوقت.
  2. سيظهر المتبقي (الآجل) باللون الأحمر.
  3. عند الحفظ، سيتم تسجيل المدفوعات في الخزينة وتسجيل المتبقي كمديونية على العميل.
