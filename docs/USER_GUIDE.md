# دليل المستخدم - نظام Wholesale POS

## 1) ما وظيفة النظام؟

النظام مصمم لإدارة نشاط البيع بالجملة والقطاعي من مكان واحد، ويشمل:

- نقطة بيع (POS) سريعة ومرنة
- إدارة المنتجات والمخازن وحركة المخزون
- إدارة العملاء والمديونيات
- إدارة الشيفتات والحسابات والحركة المالية
- إدارة الشحن وحالات التسليم
- الإشعارات الداخلية ومتابعة العمليات

---

## 2) تسجيل الدخول وأول استخدام

1. افتح رابط النظام.
2. أدخل اسم المستخدم وكلمة المرور.
3. إذا ظهرت شاشة الإعداد الأولي (Onboarding) أكمل الخطوات المطلوبة.
4. بعد الدخول ستنتقل إلى لوحة التحكم.

إذا لم تتمكن من الدخول:

- تأكد من بيانات الدخول.
- تواصل مع مدير النظام للتأكد من صلاحياتك.

---

## 3) لوحة التحكم

من لوحة التحكم يمكنك:

- متابعة مؤشرات الأداء الرئيسية
- فتح تقارير هامش الربح وربح المبيعات
- الوصول السريع إلى المبيعات والمخزون والعملاء والمالية

---

## 4) شاشة نقطة البيع (POS)

المسار: **المبيعات -> نقطة البيع**

خطوات إنشاء فاتورة:

1. اختر العميل أو اتركه "عميل نقدي".
2. أضف المنتجات إلى السلة.
3. عدّل الكميات والأسعار عند الحاجة.
4. أضف الخصم ومصاريف الشحن والملاحظات.
5. أكمل الدفع واعتمد الطلب.
6. اطبع الفاتورة إذا لزم.

مميزات POS:

- نسخة مكتبية ونسخة موبايل
- حفظ مسودات الفواتير وفتحها لاحقًا
- طباعة مباشرة أو عرض/تنزيل الفاتورة

---

## 5) المسودات في POS (مهم جدًا)

يمكنك حفظ أي سلة غير مكتملة كمسودة للرجوع لها لاحقًا.

العمليات المتاحة:

- حفظ مسودة
- فتح مسودة
- حذف مسودة
- طباعة مسودة

الحفظ التلقائي عند التحديث:

- إذا كانت السلة تحتوي أصنافًا وتم تحديث الصفحة، يحاول النظام حفظها تلقائيًا كمسودة.
- بعد إعادة فتح الصفحة ستظهر رسالة:
  - **"تم حفظ السلة تلقائيًا كمسودة عند التحديث"**
- إذا كانت السلة فارغة، لن يتم حفظ أي مسودة.

---

## 6) إدارة الطلبات والفواتير

المسار: **المبيعات -> الطلبات**

يمكنك:

- استعراض الطلبات السابقة
- البحث والتصفية
- فتح تفاصيل الطلب
- طباعة الفاتورة
- إدارة المرتجعات حسب الصلاحيات

قد تتوفر أيضًا (حسب صلاحياتك):

- تعديل بعض بيانات الطلب
- حذف/إلغاء طلب

---

## 7) إدارة المنتجات والمخزون

المسار: **المنتجات**

الوظائف الأساسية:

- إضافة/تعديل/حذف منتج
- إدارة التصنيفات
- إدارة الموردين
- تسجيل فواتير الشراء ومدفوعات الموردين
- استيراد/تصدير المنتجات (Excel/PDF/باركود/QR)

إدارة المخازن:

- إنشاء وتعديل المخازن
- تحويل مخزون بين المخازن (فردي أو جماعي)
- متابعة حركات المخزون
- جرد وتدقيق المخزون

---

## 8) إدارة العملاء (CRM)

المسار: **العملاء**

يمكنك:

- إضافة وتعديل بيانات العملاء
- البحث بالاسم أو رقم الهاتف
- متابعة الأرصدة والمديونيات
- تسجيل سداد مديونية
- طباعة قائمة العملاء وتقاريرهم

أدوات جماعية:

- إضافة عملاء بالجملة
- استيراد ملف عملاء
- تنزيل نموذج الاستيراد

---

## 9) القسم المالي

المسار: **المالية**

الوظائف:

- فتح شيفت جديد
- إضافة واستعراض المعاملات
- إدارة الحسابات (نقدي/بنكي/محفظة)
- تنفيذ سحوبات
- إغلاق الشيفت وطباعة الملخص

أفضل ممارسة:

- لا تترك شيفت مفتوحًا بنهاية اليوم.
- طابق النقدية الفعلية مع المتوقعة قبل الإغلاق.

---

## 10) قسم الشحن

المسار: **الشحن**

يمكنك:

- إنشاء شحنة من الطلب
- إدارة شركات الشحن
- تحديث حالة الشحنة
- تحديث حالة الدفع الخاصة بالشحن
- طباعة ملصق الشحن

هذا القسم مهم جدًا لطلبات الأونلاين والتوصيل.

---

## 11) الإشعارات

المسار: **الإشعارات**

يوفر:

- عرض الإشعارات الجديدة
- فحص الإشعارات غير المقروءة
- تعليم إشعار كمقروء
- تعليم الكل كمقروء

قد يتم إرسال رسائل عامة من المدير لجميع المستخدمين.

---

## 12) الإعدادات والنسخ الاحتياطي

المسار: **الإعدادات**

يمكنك:

- تعديل إعدادات النظام العامة
- تنزيل نسخة احتياطية من قاعدة البيانات
- استيراد قاعدة بيانات

تنبيه مهم:

- خذ نسخة احتياطية قبل أي استيراد.
- يفضل أن تتم عمليات الاستيراد بواسطة المدير فقط.

---

## 13) الصلاحيات والأدوار

ما يظهر لك داخل النظام يعتمد على دورك.

أمثلة شائعة:

- الكاشير: المبيعات + بعض وظائف العملاء
- المخزن: المنتجات والمخازن والتحويلات
- المالية: الشيفتات والحسابات والمعاملات
- المدير: صلاحيات كاملة وإدارة المستخدمين والإعدادات

إذا لم تجد شاشة أو زرًا متوقعًا، تواصل مع مدير النظام.

---

## 14) حل المشكلات الشائعة

### أ) رسالة JSON مثل:
"Unexpected token '<' ... not valid JSON"

غالبًا تعني أن الواجهة كانت تتوقع JSON لكن الخادم أعاد صفحة خطأ HTML.

الإجراء:

- حدّث الصفحة مرة واحدة
- راجع آخر الأخطاء المسجلة
- اطلب من المسؤول التقني مراجعة السجل

### ب) خطأ قاعدة بيانات مثل:
"no such table ..."

السبب غالبًا: لم يتم تطبيق الـ Migrations.

يقوم المسؤول التقني بتشغيل:

```bash
source venv/bin/activate
python manage.py migrate
```

### ج) بطء في بعض الصفحات

- استخدم بحثًا أدق بدل البحث الواسع
- أغلق التبويبات غير الضرورية
- اطلب أرشفة البيانات القديمة إذا كانت التقارير ضخمة

---

## 15) قائمة التشغيل اليومية

بداية اليوم:

1. تسجيل الدخول ومراجعة لوحة التحكم.
2. فتح شيفت جديد (للمستخدم المسؤول).
3. التأكد من اختيار المخزن الصحيح في POS.

أثناء اليوم:

1. تنفيذ عمليات البيع من POS.
2. حفظ المسودات للطلبات المؤجلة.
3. تحديث بيانات العملاء والمديونيات.
4. تسجيل المصروفات والإيرادات الإضافية بدقة.

نهاية اليوم:

1. مراجعة الطلبات والمرتجعات.
2. متابعة الشحنات المعلقة.
3. إغلاق الشيفت وطباعة الملخص.
4. أخذ نسخة احتياطية من قاعدة البيانات.

---

## 16) دليل سريع للمدير (Quick Start)

عند تجهيز النظام لأول مرة:

1. ضبط الإعدادات الأساسية وهوية النشاط.
2. إنشاء المخازن وإدخال الرصيد المبدئي.
3. استيراد المنتجات والعملاء.
4. إنشاء المستخدمين وتحديد الأدوار.
5. اختبار دورة عمل كاملة:
   - إضافة منتجات للسلة
   - حفظ/فتح مسودة
   - إتمام بيع
   - طباعة فاتورة
   - إغلاق الشيفت
